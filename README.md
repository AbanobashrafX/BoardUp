BoardUp - Personal Kanban Task Manager

A modern, self-hosted personal task management system built with Django REST Framework and React. Features a Kanban-style board for organizing tasks into To Do, In Progress, and Done columns.

### Features
- ✅ Kanban board with drag-and-drop
- ✅ Task CRUD operations
- ✅ Categories and priority levels
- ✅ REST API backend
- ✅ Modern React frontend
- ✅ Self-hosted (runs locally)

### Tech Stack
- Backend: Django + Django REST Framework
- Frontend: React 18
- Database: SQLite
- Orchestration: Python + npm

### Quick Start
git clone https://github.com/yourusername/boardup.git
cd boardup
python main.py
